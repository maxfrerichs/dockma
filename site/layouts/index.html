dockma

Lightweight Docker on macOS,
free and open source.

GitHub → Quick start ↓

Status: early & experimental · Apple Silicon only · tested on macOS 27

tl;dr

dockma boots a lightweight Linux VM with Apple's Virtualization.framework and runs the Docker Engine inside it. The macOS docker CLI communicates to it through a Unix socket. A launchd job keeps it running in the background.

Quick start

{{ partial "quickstart.html" . }}

Needs an Apple Silicon Mac, Xcode with Swift 6.4, the docker CLI (brew install docker), and any arm64 Docker engine with buildx for the first guest build. Optional: Rosetta for amd64 images. If DOCKER_HOST is set (Lima does this), it overrides the context.

How it works

macOS
dockerdockmalocalhost:P
▼
dockma daemon launchd job · owns the VM
vsock
Linux guest dockma-agent ▼
dockerddocker-proxy/bin/sh

virtiofs: $HOME, Rosetta · virtio-blk: /var/lib/docker

A lightweight daemon owns the VM and pipes the Docker, shell and port connections to a Go agent in the guest over vsock. The guest image is built reproducibly from one Dockerfile with pinned versions; the kernel and Docker downloads are sha256-checked.
