# How to contribute

## General

Rules are easy: Everyone is welcome, except fascists, racists, homophobes, antisemites or any other kind of harmful people.
Be a decent human being. There is no general "code of conduct" (yet), but harmful behaviour would not be tolerated.

## About LLM-based tooling

I am fully aware of the negative impact of "AI". AI slop is flooding our internet, creative jobs are destroyed etc.
However, as a software engineer, "AI" is just a tool for me. A powerful tool, for sure, still a tool.

As this project was built with LLM-based tools, it is kind of hypocritic to restrict LLM usage for contributions.
Feel free to use your tool of choice.
However, there are a few guidelines if you want to contribute:

1. Human ownership: You own it. This includes opening up a PR or an issue by yourself. You should be able to understand and explain changes in your own words.
   Commits made by LLM-based tools are fine.
2. Responsible usage: If you use LLM-based tools, you should be able to explain the problem you're trying to solve.
